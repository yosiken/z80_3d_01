# models

ここに置いた `*.obj` (Wavefront OBJ) は `make` 時に自動で変換され、デモのオブジェクト一覧
(組み込み多面体の後ろ) に追加されます。表示名はファイル名 (英数字、最大 12 文字) です。

- 頂点 128 個以下、辺・面それぞれ 255 個以下 (目安は 30〜80 ポリゴン)
- 面の向きは外側から見て反時計回り (Blender の OBJ 書き出しの標準)
- 隠面処理は裏面消去のみ: 凹んだ形状は陰線消去 / シェーディングで重なりが崩れます (ワイヤーは常に正しい)

確認だけしたい場合: `python3 tools/obj2inc.py models/xxx.obj`
